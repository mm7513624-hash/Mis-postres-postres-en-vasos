MIS POSTRES - SITIO WEB

Archivos principales:
- index.html -> textos, productos, precios y estructura.
- style.css -> colores, tamaños, espacios y diseño.
- script.js -> cantidades y pedidos por WhatsApp.
- assets/ -> imágenes utilizadas en la página.

PARA CAMBIAR PRECIOS:
En index.html buscá cada producto y modificá data-price-200 y data-price-400.

PARA CAMBIAR WHATSAPP:
Abrí script.js y cambiá WHATSAPP_NUMBER por tu número.
Ejemplo Argentina: 54911XXXXXXXX

PARA CAMBIAR UNA IMAGEN:
Reemplazá el archivo correspondiente dentro de assets/ manteniendo el mismo nombre.

PARA ABRIR:
Abrí la carpeta completa en Visual Studio Code y ejecutá index.html con Live Server.
